MiniCurl

用 Go 寫的迷你 curl。可以指定請求方法、標頭、Cookie 與 Basic Auth，下載時顯示進度，也能同時向多個網址發出請求。

Go、命令列、HTTP、goroutine

  • 完整 README

開始使用

專案內附 Windows 可直接執行的 mycurl.exe。以下用 PowerShell，先進入專案資料夾：

cd .\HW1
.\mycurl.exe --help

基本語法：

.\mycurl.exe [選項] <URL1> <URL2> ...

想從原始碼編譯，需要符合 go.mod 宣告版本的 Go 工具鏈：

go mod download
go build -o mycurl.exe .

選項一覽

範例都省略了開頭的 .\mycurl.exe，需要網路連線。

功能選項範例
GET 請求直接給網址（預設）https://httpbin.org/get
指定請求方法-X、--request-X DELETE https://httpbin.org/delete
自訂標頭-H、--header（可重複）-H 'Accept: application/json' https://httpbin.org/headers
傳送文字資料-d、--data-X POST -H 'Content-Type: text/plain' -d 'Hello MiniCurl' https://httpbin.org/post
傳送檔案內容-d '@檔名'-X POST -H 'Content-Type: application/json' -d '@payload.json' https://httpbin.org/post
儲存回應-o、--output-o response.json https://httpbin.org/get
顯示請求與回應標頭-v、--verbose-v https://httpbin.org/get
跟隨重新導向-L、--location-L https://httpbin.org/redirect/1
設定逾時-m、--max-time（秒，預設 30）-m 5 https://httpbin.org/delay/2
Basic Auth--user '帳號:密碼'--user 'demo:secret' https://httpbin.org/basic-auth/demo/secret
自訂 Cookie-b、--cookie（可重複）-b 'session=abc123' -b 'theme=dark' https://httpbin.org/cookies
停用下載進度--no-progress--no-progress -o response.json https://httpbin.org/get
略過 TLS 憑證驗證-k、--insecure-k https://localhost:8443
同時請求多個網址用空白分隔，共用所有選項https://httpbin.org/get https://httpbin.org/uuid

使用時要注意

  • -d 不會自動改成 POST，也不會自動加上 Content-Type，要自己搭配 -X 與 -H。
  • 沒有指定 -o 時，回應內容輸出到標準輸出；詳細資訊、錯誤與進度輸出到標準錯誤。
  • 多個網址會同時執行，直接印在終端機時順序不固定，內容也可能交錯。加上 -o 可以分別存檔，例如 result_1.json、result_2.json。
  • 下載進度只在有指定 -o，而且伺服器提供大於零的內容長度時才會顯示。
  • 輸出檔案已存在時會被覆寫。

為什麼選 Go

不用安裝語言執行環境
Go 可以編譯成獨立執行檔。在相符的作業系統與處理器架構上，下載後就能執行，只有自己編譯時才需要 Go。
輕量的併發
goroutine 讓多個網址在同一個程序裡同時處理，不必為每個請求另外啟動程序。
執行效率好
程式編譯成機器碼，搭配併發，等待網路回應的時間可以讓其他請求繼續進行。
