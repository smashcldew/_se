在自己的電腦啟動

這個系統有 Python 後端，GitHub Pages 只能放靜態網頁，所以要在自己的電腦上執行。

需要 Python 3.11 以上。在專案根目錄開啟 PowerShell：

cd .\HW2
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py

接著開啟 http://127.0.0.1:5500。已經有 Python 環境時，也可以直接執行 start.cmd。

  • 第一次啟動會建立 HW2/data/school.db 與示範資料，之後重啟不會重設。
  • 示範帳號與密碼列在 README。
  • 5500 埠若被 VS Code Live Server 佔用，請先停止 Live Server。

系統怎麼分層

  1. 前端HTML、CSS、JavaScript，透過同源的 HTTP JSON API 溝通
  2. API 處理登入、課程、選課、課表、請假、點名
  3. 角色權限檢查每個 API 都依角色限制可做的事
  4. 資料存取層集中處理資料庫讀寫與交易
  5. SQLiteschool.db，自動建立資料表並載入示範資料

設計上的重點

  • 選課會檢查重複、容量與衝堂，並用 SQLite 寫入交易，避免多人同時選課造成超額。已有人選的課程不能刪除，容量也不能低於已選人數。
  • 密碼用 Argon2id 雜湊。登入後網頁使用 HttpOnly、SameSite Cookie，session 有效 8 小時，登出立即撤銷，資料庫只保存 token 的雜湊。
  • 以 Cookie 修改資料時須帶 X-Requested-With: SchoolPortal，後端也會拒絕跨來源操作。
  • 老師可在自己的課程開啟點名，選定日期與節次後對全班點名，一次儲存。四種角色都能在權限範圍內查閱出缺席。
  • 新增、編輯與刪除確認都用彈出視窗，可按 Esc 返回；版面支援桌面與手機。
