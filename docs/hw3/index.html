StockFollower

台股研究與追蹤的桌面程式。輸入股票代號，就能看收盤價、K 線與 KDJ 提示，也能依成交量、漲幅、跌幅列出排行。

Python、Tkinter、SQLite、證交所與櫃買中心公開資料

  • 原始碼
  • 完整 README
  • 開發驗證紀錄

本工具僅供資訊整理與研究輔助，不構成投資建議。公開資料可能延遲、缺漏或修正，使用前請自行核對。

在自己的電腦啟動

這是桌面程式，需要在自己的電腦上執行。需要 Python 3.11 以上；視窗使用 Python 內建的 Tkinter，另外只依賴 certifi 與 matplotlib。

cd .\HW3
python -m pip install -r requirements.txt
python -m stockfollower

視窗介面

視窗左邊是個股區（約 70%），右邊是排行榜（約 30%）。兩邊的查詢結果與狀態各自獨立，排行榜不會蓋掉個股報告或 K 線。

個股區
在代號欄輸入四位數代號再按「搜尋」，顯示個股報告、最新收盤價、KDJ 交叉提示，以及內嵌的 K 線與 KDJ 圖。圖表可切換日、週、月、年取樣，查詢區間為 1 到 24 個月，預設 3 個月。
排行榜
依成交量、漲幅或跌幅列出前 20 名，也可以用產業別篩選。產業別來自證交所的上市公司基本資料，顯示中文行業名稱。
支援範圍
個股查詢支援證交所（TWSE）上市與櫃買中心（TPEx）上櫃股票，依代號自動選擇資料來源，例如 2330 與 6274。排行榜目前只涵蓋上市個股，興櫃尚未支援。

資料怎麼存

查詢時才向官方公開 API 下載資料，同一次使用期間會重用快取；勾選 Refresh cache 可強制更新。啟動時會先清掉 data/cache/ 裡本程式的 twse_*.json 與 tpex_*.json 快取。

個股查詢的結果另外寫進 SQLite 資料庫 data/stockfollower.db，會持續累積，不會被啟動時的清快取動作刪掉。

資料表內容主鍵
quotes每日報價摘要：代號、名稱、市場、日期、收盤、漲跌、漲跌幅、成交量、產業別(symbol, trade_date)
daily_bars完整日線：開、高、低、收、成交量、漲跌(symbol, trade_date)
  • 只有個股查詢會寫入資料庫，排行榜查詢不會。
  • 重複查詢相同代號與日期會覆寫（upsert）。
  • 價格以字串保存，才能保留 Decimal 的精度。
  • TPEx 歷史行情的成交量由「張」換算成「股」，精度依來源資料而定。

程式結構

檔案負責
gui.pyTkinter 桌面介面（約 520 行）
providers.py向 TWSE 與 TPEx 取得行情與歷史資料
indicators.py均線與 KDJ 等技術指標
signals.pyKDJ 黃金交叉與死亡交叉提示
storage.pySQLite 儲存，PriceStore 提供 recent_prices() 與 saved_quotes()
industries.py產業別對照
models.py報價與日線的資料型別
tables.py排行榜每一列要顯示的內容

測試

tests/ 內有指標、產業別、訊號、儲存、TPEx 與回歸測試六個檔案，用 pytest 執行：

python -m pytest -q
