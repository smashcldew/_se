Git Flow 與 GitHub Flow

第四週的操作筆記：先用分支開發、合併回主分支，再練習 fork 別人的倉庫並送出 pull request。

Git、GitHub、分支、pull request

  • 原始碼
  • 完整 README
  • 母專案

操作步驟

1. 建立 dev 分支並推到 GitHub

在母專案資料夾（_se）開啟 Git Bash，建立並切換到 dev 分支，再把修改推上去：

git checkout -b dev
git add -A
git commit -m "dev branch"
git push origin dev

2. 切回 main 並合併

git checkout main
git merge dev

把 dev 的修改合併進主分支。

3. Fork

Fork 要在 GitHub 上對別人的倉庫操作，會複製一份到自己的帳號底下。

4. 送出 pull request

在 fork 出來的專案裡修改，再推上去：

git add -A
git commit -m "..."
git push

最後在 GitHub 上按「Compare & pull request」，就能把修改送回原本的倉庫。
