服務架構

瀏覽器只認得 Nginx。Nginx 依路徑把請求轉給對應的服務，其他服務都在 Compose 建立的內部網路裡互相通訊，只有 Nginx 的 8080 埠對主機開放。

容器技術用途
nginxNginx 1.27（非 root）靜態網頁與反向代理，唯一對主機開放 8080
nodeNode.js 20、Express、pg建立與查詢留言
pythonPython 3.12、Flask、psycopg讀取留言，計算字詞頻率與平均長度
rustRust計算指定上限內的質數
dbPostgreSQL 16儲存留言，資料放在 named volume

Node 與 Python 用 Compose 的服務名稱 db 連資料庫，不能用 localhost。

在自己的電腦啟動

這個專案要跑 Docker 容器，GitHub Pages 無法執行，需要在自己的電腦上啟動。

需要 Docker Desktop（含 Docker Compose v2）。在 Week6 資料夾執行：

docker compose up --build -d
docker compose ps

再開啟 http://localhost:8080。健康狀態卡每五秒更新一次。

想做的事指令
停止服務、保留資料docker compose stop，之後用 docker compose start 再啟動
移除容器與網路，volume 仍保留docker compose down
連留言資料一起刪除docker compose down -v
示範服務彼此獨立docker compose stop python

down -v 會移除 postgres_data，資料無法還原。重新建立資料庫後，db/init.sql 會再執行一次。

停掉 Python 之後，統計與 Python 的狀態會顯示離線，留言與 Rust 的質數運算仍然可以使用。

核心概念

Image（映像檔）
建置容器用的唯讀模板。docker compose build 依各服務的 Dockerfile 建置，同一個 image 可以建立多個容器。
Container（容器）
image 執行後的隔離環境。容器可以替換、停止，容器內的一般檔案不適合當永久儲存。
Volume（磁碟區）
由 Docker 管理、可跨容器生命週期保存的資料空間。postgres_data 掛載到 PostgreSQL 的資料目錄，所以移除 db 容器不會清掉留言。
Network（網路）
Compose 建立 app_net，讓服務用名稱彼此尋址，例如 node 連到 db:5432。資料庫與 API 沒有對外開放埠。
Compose
用 docker-compose.yml 描述服務、建置、環境變數、網路、volume、健康檢查與啟動順序，一次操作整個系統。
反向代理
瀏覽器只跟 Nginx 溝通，Nginx 根據路徑把請求送到內部服務，也負責提供靜態網頁。

Dockerfile 寫法重點

  1. 善用快取分層。先複製變動少的依賴清單並安裝，最後才複製常改的程式碼。只改程式時，套件安裝那一層可以沿用快取。Node 先 COPY package*.json 再 npm ci，Python 先複製 requirements.txt。
  2. Multi-stage build。用多個 FROM 階段分開建置與執行。Rust 在 builder 階段編譯，最終 image 只有執行檔與精簡的 Alpine 基底，體積小、工具也少。
  3. 不要用 root 執行程式。用 USER node 或專用的 appuser，把服務的權限降到最低。

常用指令

docker compose logs -f                              # 持續查看全部服務日誌
docker compose logs -f node                         # 只看 Node 日誌
docker compose exec db psql -U demo -d docker_demo  # 進入資料庫命令列
docker compose build node                           # 只重建 Node image
docker compose restart node                         # 重啟 Node 容器
docker image ls                                     # 列出本機 images
docker volume ls                                    # 列出 volumes
docker network ls                                   # 列出 networks
docker system df                                    # 查看 Docker 磁碟使用量
