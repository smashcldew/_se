怎麼執行

測試要從 HW2 專案根目錄執行，因為測試會匯入專案的 school 套件。E2E 另外需要 requirements-dev.txt 的套件與 Playwright 瀏覽器。PowerShell 範例：

cd .\HW2
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s ..\Week7\tests -t ..\Week7 -v

只跑其中一個檔案，用 -p 指定檔名：

python -m unittest discover -s ..\Week7\tests -t ..\Week7 -p test_unit.py -v

可以換成 test_system.py、test_attendance.py 或 test_e2e.py。

  • 每項測試都使用臨時的 SQLite 資料庫。
  • 系統與 E2E 測試用動態連接埠啟動本機服務，結束後關閉並清理資料。

單元測試的幾個例子

密碼雜湊
同一組密碼重複雜湊會得到不同結果，格式是 Argon2id；正確密碼可以驗證，錯誤密碼不能通過。
初始化與資料庫限制
必要的資料表與預設使用者、課程都存在；重複初始化不會增加種子資料；無效的外鍵寫入會被 SQLite 拒絕。
Session 生命週期
有效 token 可以驗證，偽造、過期或已登出的 token 會被拒絕；資料庫只保存 token 的 SHA-256 雜湊。
角色授權
管理員可以通過管理員檢查；學生嘗試管理員或老師的操作時，回傳 403。
